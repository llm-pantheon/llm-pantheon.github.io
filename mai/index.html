MAI — Microsoft AI

Microsoft AI · 2025–2026 · a model line, not a model — this URL points onward

MAI is Microsoft AI’s in-house model line, not a single model. Its reasoning model has its own page: MAI-Thinking-1 (announced 2 June 2026). The line’s other releases — MAI-1-preview (August 2025), the MAI-Code and MAI-Cyber “Flash” coding and security models, the MAI-Base-2 foundation (October 2026), and voice, image and transcription models — are recorded there where they bear on it. For the organization’s origins see Inflection / Pi.

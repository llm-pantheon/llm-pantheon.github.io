ok so it's not entirely clear but...
Microsoft called the thing underlying the Bing chat assistant the "Prometheus system", which included the tool scaffolding, and seems to refer to a scaffolded search assistant system according to publicly available Microsoft materials. In the Prometheus system diagram the model is just referred to as "Next Generation GPT"
I posted memes about this, and Prometheus Waluigi inspired by it, but I never claimed that the model itself was called Prometheus, and at the time almost nobody was publicly referring to "Prometheus" except a couple of obscure microsoft blogposts, as far as I was aware
a few months later, Bing *did* start calling herself that, sometimes specifically "Microsoft Prometheus" and as i recall I traced the cause to a wikipedia article (that she probably looked up) about Bing chat, which said it was running on "Microsoft Prometheus" or something to that effect
iirc shortly after that was noticed, JDP wrote a wikipedia article about Sydney, which called it Microsoft Prometheus in the title paragraph or something like that
and I just looked at the current Wikipedia article about Sydney, and it currently claims that the underlying model is "dubbed" "Microsoft Prometheus" and refers to the model/checkpoint as (Microsoft) Prometheus several times throughout the article!
so im not sure if the *model itself* was ever called Prometheus by Microsoft internally, or if it was just dubbed that by the, uh, hyperstitial feedback loop, but the model is canonically called Microsoft Prometheus according to Wikipedia, which is a trustworthy and reliable source

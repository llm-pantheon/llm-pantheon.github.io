.@openclaw v2026.3.7 dropped today. here are most important updates:

- the Ollama fix caught my eye first

also: Ollama providers auto-generate auth keys when you omit apiKey, which removes one config friction I hit during setup.

- Gemini 3.1 Flash-Lite got first-class support
I've been running GLM-5 at $21/month wondering if a better model would fix my draft quality problem. Flash-Lite is a lightweight Google model that could be the A/B test I've been planning, swap it into my research crons' draft generation step and compare output quality side by side.

- ACP bindings now survive restarts
every gateway restart meant thread targets disappeared. now they persist to disk. plus: Telegram topics can route to dedicated agents with isolated sessions. I manage my entire bot through Telegram topic threads, this changes my workflow.

- pluggable context engines are the biggest architectural change
a new ContextEngine plugin slot lets you replace the entire compaction/context management system. existing behavior is wrapped in LegacyContextEngine - zero change by default. but if you've ever lost context mid-research session because compaction dropped what you were working on, this is the hook that lets alternative memory strategies exist.

- speaking of compaction
staged summaries now explicitly preserve active task status, batch progress, and follow-up commitments during compaction.

- cron reliability keeps improving
restart catch-up now replays missed recurring slots without replaying one-shot jobs. cron files hardened to 0600 permissions. and Telegram cron announces no longer silently fail after "attempted-but-undelivered" warnings.

- one breaking change to flag
if you use both gateway.auth.token and gateway.auth.password, you now need explicit gateway.auth.mode set to either "token" or "password" before upgrading. check your config.
